# ping-monetization-analysis
# PING 수익화 전환 흐름 분석

익명 투표 SNS 앱 PING의 회원·결제 DB와 앱 행동 로그(Hackle)를 분석해, 어떤 행동이 결제로 이어지는지 찾고 결제 전환 개선안을 제안한 팀 프로젝트입니다.

- **기간:** 2026.06.25 ~ 2026.07.16 (코드잇 부트캠프 데이터분석과정)
- **내 역할:** 데이터 전처리 및 분석
- **사용 기술:** Python (pandas, numpy, matplotlib, seaborn, scikit-learn)

## 분석 배경
전체 가입자 677,081명 중 결제 유저는 59,192명(8.74%)이었습니다. "왜 결제하지 않는가"보다 "어떤 행동이 결제로 이어지는가"를 먼저 보기로 하고, 유저 흐름을 결제로 이어지는 긍정 경로와 이탈로 이어지는 부정 경로로 나눠 분석했습니다.

## 전처리
| 대상 | 처리 내용 |
|---|---|
| 회원 (accounts_user) | 운영 계정 제거, 리스트 컬럼 파싱, 친구·차단·숨김 수 파생 |
| 시간 | DB 테이블은 UTC → KST(+9시간) 변환, Hackle 로그는 KST 유지 |
| 신고·차단 기록 | 같은 유저·대상·사유로 1분 안에 반복된 기록을 1건으로 정리 |
| Hackle 로그 | 숫자형 user_id만 DB 유저와 매핑, 노이즈 이벤트 제거 |
| 학교·반 정보 | 학생 수 0명 학교, 존재할 수 없는 학년·반 제거 |

## 주요 결과
- 첫 결제의 74.2%가 가입 7일 안에 발생
- 결제 직전 가장 많이 클릭된 상품은 777하트 (소액 입문 상품 역할)
- 무료충전소 사용 유저의 결제율 33.7% vs 미사용 19.1%
- 부정 경험(신고·차단 등)이 있는 유저의 30일 이탈률이 오히려 더 낮음 (71.5% vs 77.4%)

## 제안

- 결과 확인 화면에 충전소 버튼 노출

## 파일 구성
- `ping_analysis.ipynb`: 데이터 불러오기 → DB 전처리 → Hackle 로그 전처리 → 결제 경로 EDA

## 참고
- 원본 데이터는 비공개라 포함하지 않았습니다.
- 상품 가격은 원본 데이터에 없어 가정값을 사용했으므로, 금액 기준 지표는 참고용입니다.
- 일부 결과(군집 분석, 30일 이탈률 등)는 팀원과 나눠 진행한 분석을 포함합니다.
